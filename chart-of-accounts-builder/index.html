🔒 Security Layer
Active Protections
This tool reads and writes chart-of-accounts data in your Manager.io business. Here's exactly what guards that process.
✓
Zero external tracking NO ANALYTICS
No telemetry, no analytics, no cookies, no fingerprinting. Your account data never leaves the connection between this page and your own Manager.io business.
✓
Origin-pinned messaging ACTIVE
Once Manager's host origin is established, any message claiming to be from Manager but arriving from a different origin is silently rejected — a hostile embedding page can't spoof API responses.
✓
Endpoint whitelist ENFORCED
Every request path is checked against a strict allow-list built from the exact chart-of-accounts endpoints this tool needs. Nothing else can ever be called, even if a response tried to smuggle a rogue URL.
✓
One trusted library only MINIMAL
The only external code this page loads is the spreadsheet library (ExcelJS, from cdnjs) used to build and read your import files. No analytics, ad, or tracking scripts are loaded from anywhere.
✓
XSS-safe rendering ESCAPED
Account names and codes — including anything from an uploaded Excel file — are HTML-escaped before being displayed, so a hostile value can't execute code in the page.
✓
You approve every write PREVIEW FIRST
Every bulk import shows a full preview — including which rows will be created vs. updated — before a single request is sent. Nothing is written silently.
All checks run client-side, in your browser v3.0
📖 Guide
How to Use This Extension
Read this once before your first import — it'll save you a false start.
Before you touch this extension
1
Create your Groups in Manager first (manually)
This extension bulk-imports accounts into groups — it does not create the groups themselves. In Manager, go to Settings → Chart of Accounts and create every Profit & Loss and Balance Sheet group you'll need (e.g. "Operating Expenses", "Current Assets") before importing. Every group name you plan to use in your Excel file must already exist in Manager, spelled exactly the same way.
2
Create at least one Control Account "bucket" per type (manually)
In Manager, go to Settings → Control Accounts. For every type you'll use — Customers, Suppliers, Bank and Cash Accounts, Fixed Assets, Inventory Items, etc. — create at least one bucket there (e.g. a "Clients" bucket under Customers). This extension's Subsidiary Accounts import needs a bucket to attach each account to; it does not create the bucket headings for you.
3
Fixed Assets & Intangible Assets need TWO buckets each
A Fixed Asset needs both a "Fixed Assets" bucket AND a "Fixed Assets — Accum. Depreciation" bucket to point to (same idea for Intangible Assets / Accum. Amortization). You can create these manually in Manager, or import them from this same extension's Subsidiary Accounts sheet first — set Type to Fixed Assets — Accum. Depreciation or Intangible Assets — Accum. Amortization and put a Balance Sheet Group name (not a Control Account) in the Control Account 1 column for those rows.
Using the extension
4
Press "⬇ Load Data"
This pulls your current Profit & Loss accounts, Balance Sheet accounts, and all their groups from Manager. Do this every time you open the extension, and again after making changes directly in Manager.
5
Pick a tab: Profit & Loss, Balance Sheet, or Subsidiary Accounts
Profit & Loss / Balance Sheet — your normal chart-of-accounts lines (Code, Name, Group). Subsidiary Accounts — the detailed lists behind a control account: Customers, Suppliers, Bank and Cash Accounts, Fixed Assets, Inventory Items, and more, all in one combined table.
6
Report tab — browse, search, edit
Click any column header to sort. Type in the search box to filter instantly. Click ✏️ Edit on any row to change its Code, Name, Group, or Control Account directly. On Profit & Loss / Balance Sheet, you can also tick rows and use 🔢 Bulk Number to auto-assign sequential codes.
7
Bulk Import tab — the main event
Click ⬇ Download Template first — every template includes a full "📖 Instructions" sheet plus reference sheets listing every valid Group / Type / Control Account name in yourcreate or update so you know exactly what will happen.
8
Re-importing is always safe
Fixed a typo? Adding more rows later? Just re-upload — matching is done by Code. A Code that already exists gets updated, never duplicated. A new Code gets created. You can re-run the same file as many times as you like.
9
If something fails
Every error shows the real message from Manager directly on screen — no digging required. If you want the full technical detail, open your browser's console (F12) and look for lines starting with [API POST] or [API PUT].
You can reopen this any time from the 📖 Guide badge v3.0

📄 Data & Source
Where Your Data Goes — Exactly
This describes what the code actually does, not a marketing summary. You can verify every claim by viewing this page's source — it's a single HTML file, nothing minified or hidden.
✓
Where data comes from
All account data is read live from the Manager.io business you currently have open, using the API address and access token Manager itself hands this page when it loads (via postMessage). This page has no accounts, credentials, or data of its own — it only ever shows what your Manager business already contains.
✓
Where data goes when you Load / Edit / Import
Every request goes to exactly one place: your own Manager.io API endpoint. There is no other server in the loop — no analytics backend, no logging service, no third-party API. The full list of paths this tool will ever call is hard-coded in the page (the ALLOWED_API_PREFIXES whitelist) and enforced before every request.
✓
The one external connection that isn't Manager
This page loads one JavaScript library — ExcelJS, from cdnjs.cloudflare.com — to build and read the .xlsx template files. That library never receives your Manager data; it only runs inside your browser to construct the spreadsheet you download or read the one you upload.
✓
Your Excel file never leaves your browser
When you upload a bulk-import spreadsheet, it's read directly in memory in your browser tab. It is not uploaded to any server — the parsed rows go straight from the file into the same Manager API calls described above.
✓
Nothing is stored between sessions
This page uses no localStorage, sessionStorage, cookies, or any browser database. Everything you see lives only in memory while the tab is open — reload the page and it's gone, back to a clean state.
✓
No tracking of any kind
No analytics scripts, no tracking pixels, no error-reporting services, no fonts or assets pulled from a tracking CDN. The only thing sent anywhere is the account data required for the action you explicitly took (Load, Edit, or Import).
Every claim above can be checked in the page source v3.0
